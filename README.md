# анти-ии квен академия биология егэ-2027

🧬 бесплатный социальный офлайн-тренажёр для подготовки к ЕГЭ по биологии 2027 года.
один HTML-файл: без установки, без интернета, без рекламы и без сбора данных.

## 📋 об экзамене (проект ФИПИ 2027)

| параметр | значение |
|---|---|
| заданий | 28: 21 с кратким ответом + 7 с развёрнутым |
| максимум | 57 первичных баллов (часть 1 — 35, часть 2 — 22) |
| время | 235 минут (3 ч 55 мин) |
| калькулятор | непрограммируемый, разрешён |

изменения-2027: структура КИМ без изменений; задание 21 — 1 балл (было 2); задание 26 — 4 балла (было 3).

## ⚙️ что внутри

- 🧪 **тренажёр 28 заданий** по демоверсии ФИПИ-2027: вопрос → подсказка «что проверяет задание и как думать» → ввод ответа → разбор с источником
- ✅ **автопроверка части 1 по правилам ФИПИ**: точные позиции, множества без учёта порядка, последовательности — с частичными баллами 2/1/0
- ⚠️ **часть 2** — приближённая автопроверка по ключевым элементам ответа: учебная подсказка, не заменяет экспертную проверку по критериям ФИПИ
- ⏱ **таймер экзамена**: 235 / 60 / 30 минут, предупреждение за 5 минут до конца
- 📊 **живой прогресс**: пройденные блоки, верные ответы, первичные баллы, итог из 57
- ☑️ **чек-лист подготовки** — 20 пунктов по всем разделам кодификатора
- 🗓 **план подготовки на 25 дней** — от диагностики до финального пробника
- 🌍 интерфейс **RU / EN**
- 🛡 **анти-ИИ подход**: ИИ часто ошибается в генетике, цитологии и анализе эксперимента — учимся проверять условия, обосновывать выводы и не списывать у нейросети

## 🔒 приватность

ответы и чек-лист живут только в памяти вкладки и сбрасываются при перезагрузке страницы.
никаких localStorage, серверов, cookie и аналитики.

## 🚀 запуск

- **офлайн:** скачай `index.html` и `favicon.ico` в одну папку → открой `index.html` в любом браузере
- **онлайн:** GitHub Pages проекта

## 📁 файлы

- `index.html` — всё приложение (HTML + CSS + JS)
- `favicon.ico` — оригинальный логотип проекта (шапка приложения + иконка вкладки)

## ⚠️ дисклеймер

учебный проект по открытым материалам ФИПИ (демоверсия, спецификация, кодификатор ЕГЭ-2027).
с ФИПИ не аффилирован. автопроверка части 2 приближённая — итоговый балл сверяй с официальными критериями.
